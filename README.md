# Emelowsky Plugins — ReaPack repository

REAPER scripts by Emelowsky Plugins. Every script runs as a free DEMO with no time limit; a license key from Gumroad unlocks the full version in the same file.

**Shop (all products):** https://emelowsky.gumroad.com

## Add this repository in REAPER

Extensions → ReaPack → Import repositories… and paste:

    https://raw.githubusercontent.com/Emelowsky/reapack/main/index.xml

Then Extensions → ReaPack → Browse packages.

## Packages

| Package | What it is | Buy |
|---|---|---|
| Emelowsky - Plugin Shelf for REAPER | Visual plugin and FX chain browser: plugins as thumbnails, your own categories, Quick Switch, search by bits of words, presets, Override for REAPER's FX button | https://emelowsky.gumroad.com/l/plugin-shelf |
| Emelowsky - Plugin Shelf for REAPER (icon pack) | 4125 plugin icons for Plugin Shelf, installed next to the script | free |

Files install to `Scripts/Emelowsky/<Product>/`. REAPER 7 (Lua 5.4); REAPER 6 users take the Lua 5.3 package from the Gumroad download. Requires ReaImGui.
